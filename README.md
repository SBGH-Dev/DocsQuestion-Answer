# Docs Question Answer

A simple AI-powered document Q&A app built just for fun during my free time to experiment with connecting to the OpenAI API.

Users can:

- Upload a document
- Ask questions about the uploaded content
- Use their own OpenAI API key

## Notes

- No database used
- No backend authentication
- No user accounts
- Everything is stored locally in the browser using localStorage
- API keys are never stored on any server

This project was made mainly for learning and experimenting with OpenAI integration and document-based AI interactions.

## Tech Stack

- JavaScript
- HTML
- CSS

## Disclaimer

This is a small experimental project and was not built for production use.
